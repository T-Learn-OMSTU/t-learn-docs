## Разработка Backend

1. **ЯП:** Kotlin
2. **IoC container:** Spring
3. **Работа с БД:** JDBC, JOOQ
4. **Брокеры сообщений:** Apache Kafka
5. **Сборщик:** Gradle

## QA

1. **Автоматизация:** ЯП Kotlin
2. **Framework:** JUnit
3. **Виртуализация для локального тестирования:** Docker
4. **Тестовые артефакты:** Allure + `io.qameta.allure` для интеграции из автотестов
5. **Инструменты тестирования API:** Postman

## Разработка Frontend

1. **Сборка и база:** React 19 + TypeScript + Vite
2. **UI и стили:** shadcn/ui + Tailwind CSS
3. **Карточки и шторки:** Pure CSS3 + Vaul
4. **Серверный стейт:** TanStack Query v5
5. **Клиентский стейт:** Zustand
6. **Роутер:** React Router v6
7. **Графики:** Recharts
8. **Формы:** React Hook Form + Zod
9. **Excel:** xlsx (SheetJS)
10. **Тесты:** Vitest + Playwright
11. **Деплой:** Docker
