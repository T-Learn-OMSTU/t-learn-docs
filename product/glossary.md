# Глоссарий проекта

* **Админка (Панель администратора)** - веб-интерфейс для модераторов и администраторов, предназначенный для управления словарями, контентом и просмотра статистики.
  
* **Администратор (Administrator)** - роль с полным набором прав модератора, дополнительно наделенная возможностью управлять привилегиями других пользователей (назначать модераторов и администраторов).
  
* **Бадж (Badge)** - визуальный индикатор (значок) на кнопке перехода в раздел, сигнализирующий о наличии нового контента.
  
* **Bottom Sheet** - это UI-паттерн, который появляется снизу экрана и перекрывает основной контент частично или полностью.
  
* **Выученное слово** - слово, которое успешно прошло все 8 этапов повторения в ротации и больше не показывается пользователю при стандартном обучении.
  
* **Диплинк (Deep link)** - специальная ссылка, перенаправляющая пользователя из почты непосредственно в определенный раздел приложения.
  
* **Карточка слова** - основной элемент интерфейса модуля обучения, содержащий слово, транскрипцию, скрытый перевод и кнопки действий.
  
* **Карточка слова в ротации** - карточка для повторения уже изученного ранее слова; может иметь тип «английский -> русский» или «русский -> английский» (выбирается случайно при каждом повторении).
  
* **Лидерборд (Leaderboard)** - модуль соревнований между пользователями, отображающий рейтинг пользователей по количеству выученных слов за текущий календарный месяц.
  
* **Мануальное повторение** - функция в настройках, позволяющая принудительно запустить уже выученные слова в ротацию с наивысшим приоритетом для однократного повторения без перехода по этапам.
  
* **Модератор (Moderator)** - роль в панели администратора с правами просмотра статистики пользователей, управления словарями (загрузка, редактирование, выгрузка) и контентом раздела *Content of the day*.
  
* **Пуш-уведомления (Push)** - всплывающие уведомления, напоминающие пользователю о необходимости повторить слова, о выходе нового контента дня или об итогах лидерборда.
  
* **Редирект (Redirect)** - автоматическое перенаправление пользователя с одного экрана приложения на другой.
  
* **Ротация** - механизм интервального повторения слов в виде приоритетной очереди карточек, в которую слово попадает после нажатия кнопки «Я не знал этого слова».
  
* **Синхронизация прогресса** - процесс передачи и сохранения данных об изученных словах и текущих этапах ротации с устройства пользователя на сервер.
  
* **Словарь** - тематический или базовый набор пар английских слов (с транскрипцией и указанием части речи) и их переводов на русский.
  
* **Сплэш-скрин (Splash screen)** - стартовый загрузочный экран приложения, с которого пользователь перенаправляется либо на экран авторизации, либо сразу в модуль обучения.
  
* **Токен авторизации** - уникальный ключ доступа, выдаваемый сервером на 30 дней, используемый для запросов в авторизованной зоне.
  
* **Экшн (Action)** - целевое действие пользователя в интерфейсе (например, свайп/нажатие кнопки для карточки слова или реакция на пуш-уведомление).
  
* **Этап повторения** - один из 8 интервалов времени, через которые слово в ротации должно быть показано пользователю для закрепления (5 минут, 1 час, 1 день, неделя, месяц, 3 месяца).
